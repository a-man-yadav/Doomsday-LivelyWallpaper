# AVENGERS: DOOMSDAY — Live Wallpaper Installation Guide

## 🪟 Windows Setup (Lively Wallpaper)

1. **Clone or Download** this repository to your computer:
   ```bash
   git clone https://github.com/a-man-yadav/Doomsday-LivelyWallpaper.git
   ```
   *(Or click **Code -> Download ZIP** on GitHub and extract the folder). **->** Works best with Lively Wallpaper.*

2. Open **[Lively Wallpaper](https://github.com/rocksdanister/lively)** on your Windows PC.
3. Click the **`+` (Add Wallpaper)** button in the top right header.
4. Drag and drop the **`Doomsday-LivelyWallpaper`** folder directly into the Lively window.
   *(Alternatively, click **Browse** and select `index.html` inside the folder).*
5. Click **OK** to set it as your active desktop background!

---

## 🍏 macOS Setup

### Option 1: Live Wallpaper / Screensaver (WebViewScreenSaver)
1. Install **[WebViewScreenSaver](https://github.com/bodysoulspirit/WebViewScreenSaver)** for macOS.
2. Open Screensaver Settings, add a new item, and select the local `index.html` file (or your hosted GitHub Pages URL).
3. Set as your active macOS screensaver / live background!

### Option 2: Web Wallpaper Apps / Browser Fullscreen
1. Open `index.html` directly in Safari, Chrome, or Firefox on macOS.
2. Press `F` (or `Control + Command + F`) for instant fullscreen presentation mode.
3. Alternatively, use macOS desktop apps like **Pluck** or **WebToDesktop** to set `index.html` as your live desktop wallpaper.
